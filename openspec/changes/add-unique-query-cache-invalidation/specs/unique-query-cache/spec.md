## ADDED Requirements

### Requirement: 生成唯一约束查找缓存
系统 SHALL 为实体声明的单字段及组合唯一约束生成对应的默认服务 `findByXxxAndYyy` 方法，并在实体默认缓存中保存唯一查询 key 与主键的反向关联。

#### Scenario: 单字段唯一约束
- **WHEN** 实体字段声明为单字段唯一约束
- **THEN** 生成服务必须提供对应的 `findByXxx` 方法
- **AND** 该方法必须只在该唯一组合缓存开关启用且参数有效时使用实体默认缓存中的唯一查询 key

#### Scenario: 组合唯一约束
- **WHEN** 实体声明多个字段构成唯一约束
- **THEN** 生成服务必须提供按实体字段顺序命名的 `findByXxxAndYyy` 方法
- **AND** 不同唯一字段组合必须使用不同的唯一查询 key 前缀

### Requirement: 实体变更事件失效唯一查询缓存
系统 SHALL 在主键缓存被驱逐时，根据唯一查询缓存写入时建立的反向关联，清理该主键关联的全部唯一查询缓存 key。

#### Scenario: 局部更新后清空唯一缓存
- **WHEN** 单条更新仅修改唯一字段以外的属性且主键缓存被驱逐
- **THEN** 系统必须保留原有主键缓存驱逐
- **AND** 系统必须清理该主键关联的全部唯一查询缓存 key

#### Scenario: 外部写入复用实体事件
- **WHEN** 外部写入在事务提交后向实体既有主题发布 Create、Update 或 Delete 事件
- **THEN** 生成服务必须清空该实体全部唯一查询缓存分组

### Requirement: 唯一查询缓存开关
系统 SHALL 允许默认服务实现类按唯一属性组合静态设置缓存启用状态，并允许标准服务接口只读查询当前状态。

#### Scenario: 禁用组合唯一缓存
- **WHEN** 调用实现类的静态设置方法禁用一个唯一属性组合缓存
- **THEN** 对应 `findByXxxAndYyy` 方法必须绕过缓存
- **AND** 标准服务接口查询该完整属性组合时必须返回禁用状态
