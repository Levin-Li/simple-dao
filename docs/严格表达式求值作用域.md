# 严格表达式求值作用域

受信服务执行已审计的 DAO 条件表达式时，可以用 `ExpressionUtils.withRestrictedVariableResolvers(List.of(), () -> { /* 同步 DAO 查询 */ return result; })` 临时隔离当前线程已有变量解析器。严格模式只使用作用域传入的解析器列表，忽略单次求值传入的其它解析器；所有 consumer 完成后还会清除 BeanResolver。作用域退出时恢复原绑定；不支持嵌套，作用域内不能重新设置线程解析器，也不会传播到其他线程。

该作用域下，Simple DAO 构建条件时不自动混入 `DaoContext` 全局和线程变量，也不为 SpEL 配置 `BeanFactoryResolver`；本次 DAO builder 上下文与请求字段仍可使用。`#isEmpty` 和 `#isNotEmpty` 固定为框架函数，不能被同名变量覆盖。普通模式保留原行为。

只能对可信固定表达式使用该机制。SpEL 的类型、方法与构造器等能力不由本作用域禁用，调用方仍需限制表达式来源并保护其局部上下文；它不是通用脚本沙箱。跨线程调用必须在目标线程自行建立受控范围，不能依赖作用域传播。
